# Migration

Guides for moving `@cratis/components` forward across major versions. Each guide is scoped to one
version jump and lists every change a consuming app can feel — install/peer-dependency changes,
import moves, styling, and licensing.

| Guide                              | Covers                                       |
| ----------------------------------- | --------------------------------------------- |
| [2.x → 3.0](2-to-3.md)             | PrimeReact 10 → 11, peer dependencies, styling, licensing |

Moving from PrimeReact 10 to 11 is also covered from PrimeReact's own side in their
[Updating to v11](https://primereact.dev/docs/primitive/guides/migration/updating-to-v11) guide —
read it alongside [2.x → 3.0](2-to-3.md) for anything this library doesn't wrap directly.
