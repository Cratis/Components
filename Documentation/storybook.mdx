Use the **Renderer** control to run a story with the built-in renderer, Material UI, PrimeReact 11, or PrimeReact 10. Changing renderer remounts the preview iframe.

Use the **Appearance** toolbar to switch between light and dark baseline modes.

Every story generates an autodocs page from public component types and TSDoc.
